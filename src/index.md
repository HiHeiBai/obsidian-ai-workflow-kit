# My Knowledge Base

Start here. Put your work in the appropriate area; agent rules and templates live in the system area.

## What do you want to do?

- **Capture an idea or something to sort** → [Inbox](01-Inbox/README.md)
- **Move a project forward** → [Projects](10-Projects/README.md) · [Project registry](10-Projects/PROJECTS-REGISTRY.md)
- **Organize research** → [Sources](40-ExternalSources/README.md)
- **Keep a reusable method** → [My experience](20-SharedAssets/01-user-assets/README.md)
- **Resume with an AI agent** → [Agent entry](00-AI/START-HERE.md)

## Where things belong

| Location | Contents |
|---|---|
| `01-Inbox/` | Unsorted ideas, materials, and tasks that need a queue |
| `10-Projects/` | Project goals, current facts, decisions, and next actions |
| `40-ExternalSources/` | Research and source analysis, grouped by topic |
| `20-SharedAssets/01-user-assets/` | Your methods, checklists, and reusable lessons |
| `00-AI/` | Agent entry, rules, templates, recall, and helper scripts; full installs also contain guides and examples |

## First use

1. Read the [project registry](10-Projects/PROJECTS-REGISTRY.md).
2. Send this prompt to an AI agent that can access your local files:

```text
Read 00-AI/START-HERE.md in this vault and help me create my first project: <name and goal>.
```

3. Return to the project page for current facts and the next action. Store reusable methods in your own experience area.
