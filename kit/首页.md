# 我的知识库

从这里开始。日常只需把内容放进合适的工作区，AI 的开工规则和模板已放在系统区。

## 我现在要做什么

- **存一条想法或待处理资料** → [收件箱](01-收件箱/README.md)
- **推进一个项目** → [项目区](10-项目/README.md) · [项目登记表](10-项目/项目登记表.md)
- **整理读到的资料** → [资料区](20-资料/README.md)
- **留下可复用的方法** → [我的经验](30-经验资产/06-本地经验/README.md)
- **让 AI 接着做** → [AI 开工入口](00-入口/开始这里.md)

## 文件放在哪里

| 位置 | 放什么 |
|---|---|
| `00-入口/` | AI 的开工入口；人从当前首页开始 |
| `01-收件箱/` | 暂未整理的想法、资料和确需排队的任务 |
| `10-项目/` | 每个项目的目标、当前状态、决策和下一步 |
| `20-资料/` | 按主题整理的资料与分析 |
| `30-经验资产/06-本地经验/` | 自己总结的方法、检查清单和经验 |
| `90-系统/` | 规则、模板、召回和辅助脚本；完整安装还含使用指南与示例 |

## 第一次使用

1. 在 [项目登记表](10-项目/项目登记表.md)了解项目如何登记。
2. 把这句话发给能访问本地文件的 AI：

```text
请阅读这个知识库的 00-入口/开始这里.md，帮我建立第一个项目：<项目名和目标>。
```

3. 做完后，回到项目页查看当前状态和下一步。经验总结写入自己的经验区。
